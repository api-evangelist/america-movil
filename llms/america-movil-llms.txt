# América Móvil

> The largest telecommunications group in Latin America — Telcel and Telmex in Mexico, Claro across Latin America and the Caribbean, and A1 Telekom Austria Group in Central and Eastern Europe. Roughly 331 million wireless subscribers across 23 countries. For developers, the group has no corporate developer portal: the only callable API surface belongs to one operating company, Claro Brasil, through the registration-gated Claro Insight marketplace.

Generated by the API Evangelist enrichment pipeline (2026-07-25) from this repository's apis.yml and artifacts. The provider's own llms.txt — consumer/brand oriented, published by Claro Brasil and containing no developer content — is saved verbatim alongside this file as america-movil-claro-llms.txt.

## What exists

- Claro Brasil publishes 14 network and identity APIs in the Claro Insight marketplace. Product pages, plans and code samples are public; Swagger downloads, endpoints and credentials require registration.
- Two OpenAPI documents were recovered from the marketplace's own public file store: CAMARA-derived SIM Swap (3.0.3) and Mobile LBS Devices Locations (3.0.0).
- Telcel launched GSMA Open Gateway in Mexico on 28 May 2025 with SIM Swap, Number Verification and Device Location — but publishes no portal, no specification and no sandbox, only a sales contact form.
- América Móvil is a GSMA Open Gateway participant. It is NOT an Aduna equity partner. In Brazil its CAMARA APIs also reach developers through the CPaaS aggregator Infobip.

## APIs

- [Claro SIM Swap](https://www.claroinsight.com.br/pt-br/sim-swap): CAMARA-derived SIM Swap. POST /retrieve-date and POST /check. Base: https://api.claro.com.br/mobile/v1/gsma/gateway/simswap
- [Claro Device Location Retrieval](https://www.claroinsight.com.br/pt-br/device-location-retrievel): LBS network location and the Open Gateway /devicelocation/retrieve endpoint.
- [Claro Device Location Verify](https://www.claroinsight.com.br/pt-br/device-location-verify): CAMARA location verification (v0.1.0). Subject consent is mandatory under LGPD.
- [Claro Number Verification](https://www.claroinsight.com.br/pt-br/number-verification): silent network verification of the calling number, POST /verify.
- [Claro Know Your Customer](https://www.claroinsight.com.br/pt-br/claro-kyc): KYC Match against carrier records.
- [Claro KYC Fill In](https://www.claroinsight.com.br/pt-br/fill-in): returns verified registration data from an MSISDN.
- [Claro Number Recycling](https://www.claroinsight.com.br/pt-br/number-recycling): has this number changed owner since a given date?
- [Claro Tenure](https://www.claroinsight.com.br/pt-br/tenure): how long the line has been held, plus plan class (PAYG / PAYM / Business).
- [Claro Geofencing](https://www.claroinsight.com.br/pt-br/geofencing): M2M geofence subscriptions with webhook notifications.
- [Claro Alerta](https://www.claroinsight.com.br/pt-br/claro-alerta): SIM and handset change alerts.
- [Claro Face Match](https://www.claroinsight.com.br/pt-br/facial-biometrics): biometric match against Claro's image base.
- [Claro Valida Telefone](https://www.claroinsight.com.br/pt-br/claro-valida-telefone): CPF-to-number relationship validation.
- [Claro Valida Endereço 2.0](https://www.claroinsight.com.br/pt-br/claro-valida-endereco-v2): address score from antenna triangulation.
- [Claro Score](https://www.claroinsight.com.br/pt-br/claro-score): 0-1000 credit-risk score from telecom behaviour.
- [Telcel Autenticación Móvil](https://www.telcel.com/empresas/soluciones/busines-intelligence/autenticacion-movil): Mexico Open Gateway sales listing — not callable.

## How to call it

- Auth: OAuth 2.0 client credentials at https://api.claro.com.br/oauth2/v1/token. Newer Open Gateway APIs use `Authorization: Bearer`; the 2019-generation "customers" APIs use a non-standard `x-client-auth` header plus `X-CustomerID`. Geofencing also needs `X-API-Key`.
- Access is not self-serve: register at https://www.claroinsight.com.br/user/register, request the API, wait for approval.
- Plans: a free Trial (1,000 requests over 3 months) then metered Pay Per Use under contract. No public rate card.
- Errors: one estate-wide status-code contract at https://api.claro.com.br/docs. HTTP 410 marks retired APIs and versions; 451 marks legal/geographic refusal; 429 marks the contracted request policy being exceeded.
- No idempotency keys, no pagination, no status page, no SLA, no SDKs, no MCP server.
